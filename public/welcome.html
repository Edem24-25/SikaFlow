📋 Étapes de Démarrage:
  1. Créer la base de données - Utilisez phpMyAdmin ou MySQL
  2. Installer Composer - composer install
  3. Exécuter les migrations - php artisan migrate
  4. Accéder à l'application - http://localhost/sikaflow_laravel/public
